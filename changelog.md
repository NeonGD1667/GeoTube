# Changelog

All notable changes to GeoTube will be documented here.

## v0.0.1 alpha 1

### Added

* Initial GeoTube release.
* YouTube integration inside Geometry Dash.
* Cross-platform WebView architecture.
* Geode settings for GeoTube.
* GitHub Issues support.
* Initial Windows, macOS, iOS, and Android build targets.

### Notes

* GeoTube is currently in **alpha**.
* Features and APIs may change in future versions.
* Bugs are expected during early development.
